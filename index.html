Project Overview

I built on digital input and output skills by creating a memory game with four LEDs, four pushbuttons, a buzzer, and an Arduino.

I looked up a YouTube tutorial for an Arduino memory light game and used it as a starting point. From there, I built the circuit, tested it, debugged several hardware problems, and then modified the code to make the game more challenging.

The final version increases the difficulty every five turns by making the lights faster. I also added a short light show to indicate when the difficulty level increases.

Design & Build Timeline

The project took several attempts to get working. These steps show how the circuit developed from the first wiring attempt to the finished game.

01

Starting the circuit

I found a YouTube tutorial for an Arduino memory light game and used it as a starting point. I began placing the LEDs, buttons, resistors, and wires on the breadboard.

Initial setup of the components on the breadboard.
02

Working through the wiring

Getting the wiring correct was harder than expected. I had to restart multiple times because wires were in the wrong spots, some lights were not working, and leftover parts from previous projects were still stuck in the breadboard.

The circuit while I was working through the wiring and connections.
03

Connecting the Arduino pins

Connecting the wires to the Arduino pins was especially tricky because each wire had to go to a specific pin. I kept putting some of them in the wrong places, but after several attempts I got the connections right.

The full circuit connected to the Arduino.
04

Finding the next problem

I finally got the circuit working, but then the yellow light stopped working. I could not immediately figure out why, so I checked the components and their positions more carefully.

A closer look at the LEDs, resistors, buttons, and wiring while debugging.
05

Fixing the resistors

I realized that the resistors were positioned oddly. I moved each resistor one spot closer to its corresponding light. After making those changes, all of the lights worked correctly.

The resistor placement after making the fix.
06

Adding my own code changes

Once the hardware worked, I found the original code in the YouTube video's description. I used it as my starting point, then used ChatGPT to help me add my own features and make the game more challenging.

07

Increasing the difficulty

I added a difficulty system where the lights become faster every five turns. I also added a mini light show whenever the level increases so the player can tell that the game has become more difficult.

Reflection

A project like this could be useful as a simple reaction or memory game for someone who wants to practice concentration, pattern recognition, or response time. To make it more useful, I could add a display to show the player's score and level, make the buttons easier to identify, and add different game modes.

The skill I would rely on most if I continued developing this idea is debugging. A major part of this project was figuring out why something was not working, checking the physical circuit, changing one thing at a time, and testing again. Learning how to troubleshoot the wiring helped me get from repeated failed attempts to a working final circuit.
