INNOVATOR JOURNAL STARTER

UPLOAD:
1. Extract this ZIP on your computer.
2. Open your GitHub repository: https://github.com/Evanh1738/Evanh1738.github.io
3. Use Add file > Upload files.
4. Upload the CONTENTS of this folder (index.html, css folder, assignments folder, assets folder).
5. Commit the changes.
6. In GitHub, open Settings > Pages and confirm publishing is enabled from the main branch and root folder.

IMPORTANT:
- Upload the files and folders inside this ZIP, not the ZIP file itself.
- The homepage is index.html and must be in the repository root, not inside another folder.
- The assignment pages contain starter text that you should revise to match your actual work.
- To add a new assignment, make a copy of assignments/assignment-template.html, rename it, edit its content, and add a new project card to index.html.
