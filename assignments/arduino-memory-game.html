Arduino Light Memory Game

Innovator Journal — Day 8

For this project, I built an interactive memory game using an Arduino, four LEDs, four push buttons, and a speaker. The game plays a sequence of lights and sounds that the player must repeat. Each round adds another step to the sequence, making it more challenging.

1. My Starting Interest

I chose coding and electronics because I wanted to learn how code can control physical components. I was interested in building something interactive instead of only writing code on a computer. This project let me combine programming, wiring, and problem-solving.

2. Learning New Components

The main components I used were LEDs, push buttons, resistors, a speaker, a breadboard, and an Arduino board. The LEDs display the sequence, the buttons let the player enter an answer, and the speaker plays tones that match the lights.

I followed a YouTube tutorial to learn how to build and program the Arduino Light Memory Game. Watch the YouTube tutorial .

3. Building the Circuit

I started by placing the components on the breadboard and connecting them to the Arduino with jumper wires. I had to make sure the LEDs, buttons, resistors, and speaker were connected correctly so the hardware would work with the program.

4. Trial and Error: Wiring Was Harder Than Expected

At first, I wired the circuit incorrectly, so I had to take it apart and restart. Wiring everything was harder than I originally expected because each component had to connect to the correct breadboard rows and Arduino pins.

Even after rebuilding the circuit, the yellow LED would not light up. I eventually fixed it by moving its resistor one position closer on the breadboard. After that change, the LED worked properly.

This taught me that even a small wiring mistake can stop part of a circuit from working. I had to be patient, check the connections, and test changes instead of assuming a component was broken.

5. Uploading and Testing the Code

John Deng helped me connect my laptop to the Arduino when I had trouble uploading the code. Steven helped me troubleshoot the lights circuit so I could get the LEDs working correctly.

Once the program was uploaded, I tested whether the Arduino could play the sequence, read button presses, and recognize when the player entered the correct sequence or made a mistake.

6. Final Working Build

The completed setup combines four LEDs, four push buttons, a speaker, and the Arduino. The player watches and listens to a sequence, then repeats it using the buttons. Each round adds another step, making the game harder.

7. Arduino Code

The code generates a random sequence, lights up the LEDs while playing matching tones, reads the player's button presses, and checks the answers. It also plays sounds when the player completes a round or gets the sequence wrong.

#define NOTE_C4  262
#define NOTE_E4  330
#define NOTE_G4  392
#define NOTE_C5  523
#define NOTE_CS5 554
#define NOTE_D5  587
#define NOTE_DS5 622
#define NOTE_E5  659
#define NOTE_G5  784

/* Constants - define pin numbers for buttons,
   LEDs and speaker, and also the game tones: */
const byte buttonPins[] = {2, 3, 4, 5};
const byte ledPins[] = {7, 8, 9, 10};
#define SPEAKER_PIN 12

#define MAX_GAME_LENGTH 100

const int gameTones[] = {
    NOTE_C4, NOTE_E4, NOTE_G4, NOTE_C5
};

/* Global variables - store the game state */
byte gameSequence[MAX_GAME_LENGTH] = {0};
byte gameIndex = 0;

/**
   Set up the Arduino board and initialize Serial communication
*/
void setup() {
    Serial.begin(9600);

    for (byte i = 0; i < 4; i++) {
        pinMode(ledPins[i], OUTPUT);
        pinMode(buttonPins[i], INPUT_PULLUP);
    }

    pinMode(SPEAKER_PIN, OUTPUT);

    // Prime the random number generator.
    // Assumes A0 is floating (disconnected):
    randomSeed(analogRead(A0));
}

/**
   Lights the given LED and plays a suitable tone
*/
void lightLedAndPlayTone(byte ledIndex) {
    digitalWrite(ledPins[ledIndex], HIGH);
    tone(SPEAKER_PIN, gameTones[ledIndex]);
    delay(300);
    digitalWrite(ledPins[ledIndex], LOW);
    noTone(SPEAKER_PIN);
}

/**
   Plays the sequence of notes the user has to repeat
*/
void playSequence() {
    for (int i = 0; i < gameIndex; i++) {
        byte currentLed = gameSequence[i];
        lightLedAndPlayTone(currentLed);
        delay(50);
    }
}

/**
   Waits until the user presses a button and returns its index
*/
byte readButtons() {
    while (true) {
        for (byte i = 0; i < 4; i++) {
            byte buttonPin = buttonPins[i];

            if (digitalRead(buttonPin) == LOW) {
                return i;
            }
        }

        delay(1);
    }
}

/**
   Plays the game-over sequence and reports the score
*/
void gameOver() {
    Serial.print("Game over! your score: ");
    Serial.println(gameIndex - 1);

    gameIndex = 0;
    delay(200);

    // Play a Wah-Wah-Wah-Wah sound
    tone(SPEAKER_PIN, NOTE_DS5);
    delay(300);
    tone(SPEAKER_PIN, NOTE_D5);
    delay(300);
    tone(SPEAKER_PIN, NOTE_CS5);
    delay(300);

    for (byte i = 0; i < 10; i++) {
        for (int pitch = -10; pitch <= 10; pitch++) {
            tone(SPEAKER_PIN, NOTE_C5 + pitch);
            delay(5);
        }
    }

    noTone(SPEAKER_PIN);
    delay(500);
}

/**
   Gets the user's input and compares it with the expected sequence
*/
bool checkUserSequence() {
    for (int i = 0; i < gameIndex; i++) {
        byte expectedButton = gameSequence[i];
        byte actualButton = readButtons();

        lightLedAndPlayTone(actualButton);

        if (expectedButton != actualButton) {
            return false;
        }
    }

    return true;
}

/**
   Plays a sound whenever the user finishes a level
*/
void playLevelUpSound() {
    tone(SPEAKER_PIN, NOTE_E4);
    delay(150);
    tone(SPEAKER_PIN, NOTE_G4);
    delay(150);
    tone(SPEAKER_PIN, NOTE_E5);
    delay(150);
    tone(SPEAKER_PIN, NOTE_C5);
    delay(150);
    tone(SPEAKER_PIN, NOTE_D5);
    delay(150);
    tone(SPEAKER_PIN, NOTE_G5);
    delay(150);

    noTone(SPEAKER_PIN);
}

/**
   The main game loop
*/
void loop() {
    // Add a random color to the end of the sequence
    gameSequence[gameIndex] = random(0, 4);
    gameIndex++;

    if (gameIndex >= MAX_GAME_LENGTH) {
        gameIndex = MAX_GAME_LENGTH - 1;
    }

    playSequence();

    if (!checkUserSequence()) {
        gameOver();
    }

    delay(300);

    if (gameIndex > 0) {
        playLevelUpSound();
        delay(300);
    }
}

8. Reflection

How could this project be used in the real world?

A game like this could help children practice memory, attention, and pattern recognition. It could also be used as a simple introduction to electronics and programming.

What would I change or improve?

I could add clearer instructions, more difficulty settings, and feedback that helps players understand their progress. I could also improve the timing and behavior of the lights and sounds.

What skill would I rely on most?

I would rely on debugging and problem-solving. When the circuit was wired incorrectly and the yellow LED did not work, I had to check the setup, make changes, and keep trying until it worked.

9. What I Learned

This project taught me how programming and physical electronics work together. I learned that building a circuit takes careful wiring and testing, and that collaboration can help solve problems. I also gained experience finding mistakes and making changes to improve a project.
