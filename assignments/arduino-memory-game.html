Unit 1 · Day 8

Arduino Light Memory Game

For this project, I built an electronic memory game using an Arduino, LEDs, push buttons, and code. The player has to watch a sequence of lights and repeat it. This project helped me explore how hardware and programming work together.

My Process

My Starting Interest

I chose to build on my interest in coding and electronics because I wanted to understand how code can control physical components. A memory game gave me a way to combine programming with a hands-on circuit.

Learning New Components

I worked with LEDs and push buttons to create a game that responds to a player's input. I used a YouTube tutorial to learn how to build and program the project.

Building the Circuit

I assembled the circuit using an Arduino, a breadboard, LEDs, resistors, push buttons, and jumper wires. I had to check the connections and make sure the components worked together.

Debugging the Circuit

At first, I could not get the lights circuit to work correctly. Steven helped me fix the circuit, which helped me continue testing the project.

I also had trouble getting the yellow LED to work. I moved its resistor one position closer on the breadboard, and the LED started working. This taught me to check component placement instead of assuming the component itself was broken.

Improving the Code

I used code from a YouTube tutorial as my starting point and modified it. I changed the game so the lights get faster after every five turns and added a mini light show when the difficulty increases.

These changes helped me customize the game rather than only copying the original project.

Peer Support

Reflection: Applying My Learning

One possible use for this project would be a learning game for children who are practicing memory, attention, or recognizing patterns. The lights could show a pattern, and the player could use the buttons to repeat it. This could make practicing these skills more interactive.

To make my current build more useful for that situation, I would need to test the game with its intended users and adjust the difficulty so the patterns are challenging but manageable. I could also add clearer instructions, more levels, and feedback that helps players understand their mistakes.

The skill I would rely on most is debugging. I learned that a small wiring issue can stop a component from working, even when the code seems correct. If I continued developing this idea, I would test the circuit and code systematically so I could find and fix problems efficiently.

What I Learned

This project taught me that building an electronic device requires both hardware and software to work together. I practiced checking connections, troubleshooting components, uploading code, and modifying a program to improve a design. I also learned that collaboration can help me work through problems and continue making progress.
