One-Shot Game and Autopsy

Project Overview

For this project, I used WebbGPT to generate a one-shot game. I chose a simple driving simulator where the player controls a car and avoids obstacles. My goal was to see how well AI could turn a basic idea into a playable game using one prompt.

Planning and Goal Setting

I wanted my game to be simple but still fun to play. My main goals were to create car controls, obstacles, a scoring system, and a way to restart after crashing.

  • Create a playable driving game.
  • Make avoiding obstacles the main objective.
  • Track progress with a scoring system.
  • Increase the challenge as the game progresses.
  • Allow the player to restart after crashing.

My Original Prompt

can you make me code for a oneshot of a simple game, maybe a really basic driving sim where u have to drive a car and not hit obstacle on the road

My prompt explained the main idea, but I left many details up to WebbGPT, including the controls, graphics, and scoring system.

Game Features

  • Controls: Arrow keys or A/D to steer.
  • Obstacles: Avoid other cars on the road.
  • Scoring: Earn 10 points for each obstacle that passes.
  • Difficulty: The code adjusts speed and obstacle frequency.
  • Restart: Play again after crashing.

The game uses HTML, CSS, and JavaScript to display the road, draw the cars, and control the gameplay.

Game Autopsy

Looking through the code helped me understand how the different parts work together. JavaScript handles movement, obstacle spawning, scoring, and collision detection.

One potential issue is that the difficulty check can run repeatedly while the score stays at a multiple of 100. This could make the game speed up more than intended.

I could also improve the game by adding clearer instructions, better graphics, and more reliable controls.

What I Learned

This project showed me that setting clear goals helps guide a project, even when using AI to generate code. My prompt described the basic idea, and WebbGPT added features I had not specifically requested.

If I did this project again, I would make my prompt more detailed and test the finished game to make sure each feature worked as intended.

Final Reflection

Overall, this project helped me understand how an initial idea can become a more complete game through planning and goal setting. Comparing the generated code with my original prompt helped me identify what the game included and what could improve.

While writing this reflection, I also used ChatGPT to help organize my thoughts, explain parts of the code, and improve the clarity of my writing. The original game idea and prompt were mine, and I used the assistance to explain my process and learning.

By the end of the week, I want to improve my understanding of how the code works and learn how to modify it myself. I want to become more comfortable changing different parts of the game and seeing how those changes affect the final result.
