Unit 1 · Day 8

Arduino Memory Game

For this project, I built an electronic memory game using an Arduino, LEDs, and code. The goal was to create a working game that tests a player's ability to remember and repeat a sequence of lights.

The Project

My Goal

I wanted to build an interactive memory game that used lights to show a sequence for the player to remember and repeat.

Building the Circuit

I connected the Arduino, breadboard, LEDs, resistors, and other components. I had to check the wiring carefully to make sure each light worked correctly.

Troubleshooting

Some lights did not work at first, so I checked the wiring and adjusted the circuit. One yellow LED started working after I moved its resistor one breadboard position closer.

Improving the Code

I used existing code as a starting point and modified it. I made the lights move faster after every five turns and added a short light show when the difficulty increased.

Collaboration

John Deng helped me upload the code to the Arduino. I also helped Steven with his lights. Working with other people helped me troubleshoot problems and understand the project better.

What I Learned

This project taught me that building an electronic device requires both hardware and software to work together. I learned the importance of checking connections, testing components individually, and modifying code to improve a design. When something did not work, I had to investigate the problem and try different solutions instead of giving up.
